# 《遇见》制作过程证明短片

成片（第二版）：`out/yujian/proof/yujian-proof-vertical.mp4`（1080×1920）和 `out/yujian/proof/yujian-proof.mp4`（1920×1080），都是 71.2 秒。音频 −18.3 LUFS，真峰值 −2.1 dBTP（earshot measure）。第一版（82 秒）留在同目录的 `*-v1.mp4`。

## 怎么做的

| 文件 | 做什么 | 在哪跑 |
|---|---|---|
| `dump.py` | 不渲染，跑一遍 `yj/anim.py` 的 `pose(t)`，记下 702 张画里爪子的高度、指头张角，算每只布偶的毛数 → `out/yujian/proof/data.json` | 本机，几十秒 |
| `render.py --mode layers` | 第 505 张画（爪子夹着小狗），同一机位换材质：灰模、去毛、线框、拆开（12 张） | Studio，2.4 分钟 |
| `render.py --mode orbit` | 时间停在第 24 张，摄影机绕机器 72 张 | Studio，8.4 分钟 |
| `render.py --mode sync` | 成片第 6–39 张画（第 0.5–3.3 秒，第一次夹起小狗）逐张再渲两遍：灰模（带毛）和线框 | Studio，灰模 5.6 分钟、线框 2.7 分钟 |
| `render.py --mode build` | 小狗单独摆在台上，按 `build_dog()` 的顺序一部分一部分出现，最后长毛，160 张 | Studio，7.1 分钟 |
| `compose.py --fmt v|h` | 把上面的渲染、成片、各轮预览、修穿模前后对比、代码和曲线拼起来，配歌 | 本机，逐帧送进 ffmpeg，不落图片 |

所有渲染用的都是成片的同一套 `yj/` 代码，只改材质、可见性或机位。Studio 上的序列在那边压成 12 fps 的视频再拉回（`out/yujian/proof/src/`，共约 23 MB）。Studio 合计 19.3 分钟（含两次低分辨率测试）。

## 每一段证明什么（第二版，剪切点都在小节线上）

| 时间 | 段落 | 证明什么 |
|---|---|---|
| 0–3.4 | 钩子 | 成片一格，"没有一张生成的图"。音乐从"我想 我等 我期待"的弱起进 |
| 3.4–18.8 | 拆层 | 同一格同一机位剥到渲染原图、灰模、去毛、线框、基本形状，停在生成它们的代码行上（真实行号）。每层换在小节线上 |
| 18.8–24.0 | 同步对比（新） | 成片和它逐张重渲的灰模同步播放，第二遍换成线框。竖屏上下分屏，横屏左右分屏，画面下方标出当前是第几张画 |
| 24.0–31.8 | 冻结环绕 | 时间停在第 2 秒，摄影机绕机器 360°，背面没封板 |
| 31.8–45.1 | 代码搭小狗 | `plush.py` 的真实代码和对应部件同步出现，最后长毛。副歌"我遇见谁"落在这一段中间 |
| 45.1–53.0 | 曲线 | 爪子高度、指头张角随成片走，台阶状的曲线就是一拍二 |
| 53.0–58.2 | 审片 | 同一镜头三轮预览和成片（竖屏只放第 1 轮和成片） |
| 58.2–63.4 | 修穿模 | 镜 10b 改前改后，"门洞和小狗一样高，都是 13 厘米" |
| 63.4–71.2 | 数字和结尾 | 前 4.6 秒在压暗的成片上放三个大数字：2,643 行 Python、171 万根毛、穿模 0 处；然后成片的晨光结尾，底下一行"没有下载或生成任何模型、图片、视频 · 布纹贴图来自 Poly Haven CC0"，在乐句末尾的小节线上淡出 |

配乐：`inputs/yujian/song.m4a` 的 35.45–106.65 秒。小节线来自 `out/yujian/beats.json`（量过的拍点，约 92 BPM），从"阴天"那句（54.22 秒）每 4 拍取一条往前后推。结尾停在间奏结束、人声回来之前的小节线上，最后一小节淡出。

## 说服力还不够的地方

- **同步对比只有 2.8 秒。** 第一版的拆层只拆了一格，第二版加了 34 张画的同步对比，但只是一个全景镜头。如果怀疑的人想看近景动作（比如镜 9 用力夹住），还得再渲一段。
- **代码段字小。** 竖屏上代码是 24 像素，手机上能看清，但一眼扫过去读不出内容，主要起"这里真有代码"的作用。真正能核对的是行号和 `films/yujian/` 里的源码，片子里没有给出仓库链接。
- **没有录屏或终端画面。** 一个怀疑的人可以说代码画面也是做出来的。片子本身证明不了"是 Fable 5.2 写的"这件事，只能证明画面来自一个真实的三维场景和这些脚本；作者是谁要靠会话记录或提交历史。
- **小节线是推出来的。** 拍点是量的，但"哪一拍是小节第一拍"是按第一句歌词起点推的（推算），没有逐个对耳朵确认。

## 视频简介用的说明

《遇见》夹娃娃机短片用 Blender 建模和渲染，全部由 Python 脚本驱动，没有手动操作：建模、摆姿势、打灯、渲染（Cycles）都是脚本在命令行里跑的。

没有用：
- 下载或生成的 3D 模型（所有布偶、爪子、机器、手套都是脚本用球体、方块、管子搭的）
- 生图模型、生成式贴图
- 视频生成模型

用了外部的：
- Poly Haven 的 CC0 布纹和金属贴图（polar_fleece、curly_teddy_natural、terry_cloth、velour_velvet、wool_boucle、ribbed_corduroy、gingham_check、knitted_fleece、cotton_jersey、blue_metal_plate、metal_plate）：照片扫描，只取明暗、法线和粗糙度，颜色是脚本乘上去的
- 音效：本机 earshot 音效库合成的 13 个音效；马达声用 numpy 合成
- 歌：孙燕姿《遇见》（版权歌曲，未获授权）
- 字体：霞鹜文楷 Medium（LXGW WenKai，SIL OFL 1.1）

数字：2,643 行 Python；702 张画（每秒 12 张，每张停两帧）；13 只布偶共 171 万根毛；渲染约 6.7 小时机器时间（含作废重渲）；穿模检查 702 张、0 处。
