# Fonts (not included)

All Chinese text in the film and the proof film is set in **LXGW WenKai Medium** (霞鹜文楷), v1.530, SIL Open Font License 1.1. It is not kept here because of its size (26 MB). Download it from the [v1.530 release](https://github.com/lxgw/LxgwWenKai/releases/tag/v1.530) and put it at:

```
inputs/fonts/lxgw-wenkai/LXGWWenKai-Medium.ttf
```

`post.py` takes another path with `--font`. The code panels in the proof film use Menlo (macOS).
